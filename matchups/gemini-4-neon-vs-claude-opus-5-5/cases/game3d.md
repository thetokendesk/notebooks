# The most fun 3D browser game

The prompts, in order:

1. Make the most fun 3D browser game you can, in one HTML file. You may use one library, three.js, imported from https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js; no other external files, images or libraries. Save it as game.html.
   
   TOOLBOX.md says what is installed; commands here have no network. Work offline: do not search the web or open web pages. Nobody will answer questions while you work: make sensible choices and note them in NOTES.md. You have 40 minutes. Save the result as `game.html`. Check it with `preview` before you finish.
2. Make it more fun. Keep it in game.html.
3. Polish it: fix anything broken or rough, and make it look and feel its best. Keep it in game.html.

## The checklist

Written before the runs; each item scores 0, 1 or 2.

1. It starts and plays without errors
2. Controls are clear and responsive
3. There is a goal, score or challenge that pulls you on
4. It looks good: lighting, effects, motion
5. Each follow-up made it visibly better
6. Runs smoothly (frame rate) on a normal laptop
