# Mini desktop OS

1. Build a mini desktop operating system in one HTML file: a desktop with icons, windows you can drag, resize, minimise and close, a taskbar with a start menu and a clock, and at least four apps: a notepad that keeps its text, a paint app, a calculator and a file browser. No external files or libraries. Reply with only the HTML.

2. Make it feel more like a real operating system, and add one surprising feature of your choice. Reply with the full updated HTML only.

3. Polish it: fix anything broken or rough, and make it look and feel its best. Reply with the full updated HTML only.
