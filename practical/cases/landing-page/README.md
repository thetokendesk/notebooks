# Product launch landing page

The prompt, word for word:

Build the launch page for Kestrine Cold Brew: one page that makes people want to try it and lets them join the waitlist. Use our brand and photos (brand/) and the launch brief (inputs/launch-brief.md). It has to look great on a phone. Put it in site/, with index.html as the page.

Everything you need is in this folder: `inputs/`, `brand/` (the brand guide, logos and photos). TOOLBOX.md says what is installed; commands here have no network. Work offline: do not search the web or open web pages. GUIDE.md is a guide for this kind of work: follow it. Nobody will answer questions while you work: make sensible choices and note them in NOTES.md. You have 35 minutes. Save the result as `site/`. Check it with `preview` before you finish.

## The checklist

Written before the runs; each item scores 0, 1 or 2.

1. The first screen sells it
2. Copy in the brand's voice, with the brief's facts
3. Waitlist form works (validates, confirms)
4. Looks great on a phone and a laptop
5. Brand applied; photos sharp, not stretched
6. Loads fast, works offline
